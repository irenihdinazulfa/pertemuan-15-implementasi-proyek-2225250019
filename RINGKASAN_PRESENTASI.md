# Ringkasan Presentasi Rancangan Individu (±1–2 Menit)

Saya merancang **Sistem Rekap dan Analisis Nilai Matematika Kelas Berbasis Python**. Permasalahan yang ingin diselesaikan adalah proses rekap nilai siswa yang jika dilakukan manual memerlukan waktu dan dapat menimbulkan kesalahan perhitungan.

Pengguna utamanya adalah guru matematika. Program dirancang untuk membaca file berisi NIM, nama, dan nilai, memvalidasi nilai 0 sampai 100, menghitung rata-rata, minimum, maksimum, menentukan jumlah siswa tuntas berdasarkan KKM, kemudian menyimpan hasil ke laporan teks.

Alur program dimulai dari membaca file, memvalidasi setiap baris, mengolah data valid, menampilkan statistik, dan menyimpan laporan. Kodenya dibagi menjadi modul **data_io**, **analisis**, **utilitas**, dan **main** agar mudah diuji. Saya juga merancang test case normal, batas, invalid, file hilang, dan input kosong.

Walaupun bahan ajar menyebut tugas kelompok, sesuai arahan dosen proyek ini saya kerjakan **secara individu**, sehingga semua bagian dikelola oleh satu penanggung jawab. Pada Pertemuan 14 fokus saya adalah rancangan; Pertemuan 15 ditargetkan untuk integrasi dan pengujian program.
